# Spark Messenger 

Бесплатный мессенджер с открытым исходным кодом под Android.

* **Дизайн:** Material You (Jetpack Compose).
* **Приватность:** Без рекламы и подписок, чистый код.
* **Стек:** Kotlin, Jetpack Compose, Firebase Auth & Firestore.

📩 **Поддержка:** `SparkMessenger.Support@gmail.com`
**Донаты:** Boosty / Buy Me a Coffee
